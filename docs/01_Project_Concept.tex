\section{Vision}
MITA (Multimodal Interactive Tour Assistant) is a browser-based, immersive
botanical garden combining \textbf{WebVR panoramic exploration} with a
\textbf{conversational, voice-driven assistant}. Users walk through
360\textdegree{} panoramic scenes, point at plants in 3D and \emph{talk}
to the system in natural language, turning a traditional static-label
exhibit into a fluid multimodal dialogue between user, environment and
content.

\section{Characterizing Features}
\begin{itemize}
    \item \textbf{Immersive 3D environment.} Built on \textbf{A-Frame (WebVR)}
    and rendered in-browser. Five panoramic scenes (\texttt{scene-1}\ldots
    \texttt{scene-5}) are linked by clickable arrow portals; plant specimens
    (\texttt{Lavandula}, \texttt{Nephrolepis}, \texttt{Santolina},
    \texttt{Opuntia}\ldots) are positioned \texttt{glTF} models inspectable
    from any angle.

    \item \textbf{Multimodal input.} Three integrated channels:
    (i)~\emph{gaze / pointer raycasting} to select a plant in 3D;
    (ii)~\emph{speech (STT)} via the Web Speech API for hands-free queries
    (\emph{``What is this used for?''}, \emph{``Compare it with the
    lavender.''});
    (iii)~\emph{click / touch fallback} for accessibility and noisy
    environments.

    \item \textbf{Multimodal output.} Coordinated combination of a
    \emph{spatial highlight} (glow / outline) on the selected plant,
    \emph{adaptive 2D HUD cards} (botanical, medicinal, comparison,
    fallback), and \emph{TTS narration} so the user never needs to leave
    the VR view to read.

    \item \textbf{LLM-driven dialogue manager.} A minimal Node.js HTTP
    server exposes JSON endpoints (\texttt{/api/parse-intent},
    \texttt{/api/generate-info}, \texttt{/api/compare}\ldots) that perform
    LLM-backed \textbf{intent parsing} (\texttt{query\_info},
    \texttt{query\_attribute}, \texttt{compare}) and \textbf{slot
    extraction} (\texttt{medicinal}, \texttt{botanical}, \texttt{toxicity},
    \texttt{drought}, \texttt{feng\_shui}), interpreted against the selected
    plant, dialogue history and the structured \texttt{plants.json}
    database. The backend is intentionally stateless; each request
    carries all context needed for that turn so the interaction loop
    remains available even when the LLM service is offline.

    \item \textbf{Client-side interaction state.} A finite set of response
    categories (\texttt{response}, \texttt{comparison}, \texttt{fallback},
    \texttt{disambiguate}, \texttt{clarify}, \texttt{clarify\_retry},
    \texttt{error}) and \textbf{client-side state} centralised in
    \texttt{src/app/state.js} --- tracking the selected plant, visited
    plant ids, pending ambiguity candidates and dialogue history --- allow
    the assistant to reason contextually across turns without any
    persistent server session.

    \item \textbf{Robust disambiguation.} When raycasting returns overlapping
    plants, candidates are ranked by depth, labelled \emph{A / B / C} and
    announced verbally; the user resolves by voice (\emph{``the one in
    front''}, \emph{``A''}) or by clicking the overlay, with up to two
    clarification retries before falling back to pointer selection.
\end{itemize}

\section{Target Users and Why It Is Multimodal}
The system targets \textbf{casual museum visitors, botany students and
accessibility-oriented users} exploring a botanical collection on desktop,
tablet or VR headset. Rather than reading long labels, users ask focused
questions (\emph{``Can I keep this around my cat?''}, \emph{``How does it
compare to the cactus?''}) and receive concise spoken answers paired with
a visual card. MITA is multimodal \textbf{by design}: every interaction
loop fuses at least two input modalities (point + speak) and three output
modalities (3D highlight + card + voice), and degrades gracefully ---
if STT fails the user can click; if the LLM is uncertain a structured A/B
overlay takes over; if a slot is missing, a \emph{fallback card} proposes
alternatives. This redundancy keeps the experience fluent across users,
devices and ambient conditions.
