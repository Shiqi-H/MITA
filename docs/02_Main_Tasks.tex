This document describes the three interaction tasks for heuristic
evaluation, specifying the user goal, modalities, expected flow and
success criteria for each.

\section{Task 1 --- Disambiguation of Overlapping Plants}
\tasksub{Goal.} Identify \textbf{one specific plant} from a cluster of
visually overlapping specimens (e.g.\ Lavandula, Nephrolepis and Santolina
in scene~1).

\tasksub{Modalities.} \emph{Input:} raycasting + speech (STT) + overlay
click fallback. \emph{Output:} 3D highlight on each candidate, A\,/\,B
labelled overlay, TTS clarification prompt.

\tasksub{Flow.}
\begin{enumerate}
    \item User clicks or speaks while gazing at the overlapping plants.
    \item Frontend detects multiple hits, sorts by depth and labels
    candidates A, B\ldots; backend generates a spoken clarification prompt.
    \item Overlay and highlights are displayed; TTS plays the prompt.
    \item User resolves by voice (\emph{``A''}, plant name) or by clicking;
    backend matches and returns the information card.
\end{enumerate}

\tasksub{Success criteria.} Highlight and overlay appear within $\sim$1\,s;
voice resolution works for natural phrasings; two retries offered before
click fallback; no card shown until ambiguity is resolved.

\tasksub{Heuristics.} Visibility of system status; match with the real
world; error prevention and recovery (retry + click fallback).

\section{Task 2 --- Comparing the Current Plant with a Visited One}
\tasksub{Goal.} \textbf{Compare} a newly selected plant with one seen
earlier (\emph{``How does this compare to the lavender I just looked at?''}).

\tasksub{Modalities.} \emph{Input:} raycasting to select the new plant +
speech (comparison query). \emph{Output:} side-by-side comparison card
and TTS summary.

\tasksub{Flow.}
\begin{enumerate}
    \item User has visited at least one plant; its identity is stored in
    the client-side visited plant list.
    \item User selects a second plant and asks a comparison question
    (\emph{``compare it with the lavender''}, \emph{``which is more
    drought-tolerant?''}).
    \item Frontend parses the intent and sends it to the comparison
    handler with the selected plant and visited history as context.
    \item Backend resolves the target plant (by name, alias or recency),
    fetches both records and returns a spoken comparison summary.
    \item Frontend renders a side-by-side comparison card and plays TTS.
\end{enumerate}

\tasksub{Success criteria.} Implicit references (\emph{``the previous
one''}, \emph{``lavender''}) are resolved via the visited list; card
aligns matching attributes; graceful error when no second plant can be
identified.

\tasksub{Heuristics.} Recognition rather than recall; consistency and
standards; aesthetic and minimalist design.

\section{Task 3 --- Dynamic Information Card Driven by Spoken Intent}
\tasksub{Goal.} Obtain \textbf{targeted information} about a single plant
--- botanical description, medicinal use, toxicity, drought tolerance,
feng-shui symbolism --- without navigating menus.

\tasksub{Modalities.} \emph{Input:} raycasting to select the plant +
speech (STT); follow-up turns keep the plant in context. \emph{Output:}
context-sensitive card (medicinal, botanical, or general), 3D highlight
and TTS answer.

\tasksub{Flow.}
\begin{enumerate}
    \item User selects a plant; intent and topic of interest are parsed.
    \item Topic is mapped to a card type (medicinal, botanical, general).
    \item If the topic is unavailable, backend returns a fallback with
    available topics and a spoken explanation.
    \item Frontend renders the information card or a fallback card whose
    buttons re-issue requests for the same plant.
    \item Subsequent turns are contextual follow-ups using dialogue history.
\end{enumerate}

\tasksub{Success criteria.} Card type matches spoken intent; fallback
never dead-ends; follow-ups stay locked to the selected plant; TTS, card
and highlight stay synchronised.

\tasksub{Heuristics.} Flexibility and efficiency; error recovery via
fallback topics; consistency between voice and visual output.

\section*{Out-of-Scope}
\textbf{Not} evaluated: scene navigation via portals; STT/TTS audio
quality; LLM answer factuality.
